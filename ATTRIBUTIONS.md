# Open Source Credits and Attributions

ColAI relies on several open-source libraries and projects:

---

## Web Engine

- **[Mozilla GeckoView](https://mozilla.github.io/geckoview/)** (`org.mozilla.geckoview:geckoview-omni`)  
  Web engine developed by the Mozilla Foundation. Provides container context isolation (`contextId`), tracking protection, and standards-compliant rendering.  
  *License*: Mozilla Public License 2.0 (MPL-2.0)

---

## Android Libraries

- **[Jetpack Compose](https://developer.android.com/jetpack/compose)** (`androidx.compose.*`)  
  Android UI toolkit used for screens, components, and animations.  
  *License*: Apache License 2.0

- **[Jetpack Room](https://developer.android.com/training/data-storage/room)** (`androidx.room.*`)  
  SQLite database abstraction layer providing persistent storage and reactive data streams.  
  *License*: Apache License 2.0

- **[Jetpack Security Crypto](https://developer.android.com/topic/security/crypto)** (`androidx.security:security-crypto`)  
  Key management and `EncryptedSharedPreferences` using AES-256-GCM.  
  *License*: Apache License 2.0

- **[AndroidX Navigation Compose](https://developer.android.com/guide/navigation)** (`androidx.navigation:navigation-compose`)  
  Screen routing and deep link navigation.  
  *License*: Apache License 2.0

- **[AndroidX Core & Lifecycle](https://developer.android.com/kotlin/ktx)** (`androidx.core:core-ktx`, `androidx.lifecycle.*`)  
  Lifecycle handling and ViewModel management.  
  *License*: Apache License 2.0
